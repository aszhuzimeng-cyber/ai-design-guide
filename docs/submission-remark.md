# 项目申报填写参考

**项目名称**：设计指引——AI 页面生成前置可视化设计指引工具

**项目类型**：网页研究原型 / 人机协同设计工具

**项目地址**：[GitHub 公开仓库](https://github.com/aszhuzimeng-cyber/ai-design-guide)

**演示视频**：[观看项目介绍视频](https://github.com/aszhuzimeng-cyber/ai-design-guide/blob/main/docs/demo.mp4)，约 51 秒。

**Remark（推荐版）**：

> 本项目面向缺乏专业设计训练的用户，针对 AI 页面生成中“能生成、难理解、难判断”的问题，在生成前加入可视化设计认知辅助。用户通过需求澄清、设计意图确认、信息架构比较和视觉语法选择，逐步完成设计决策；系统再将选定的设计逻辑转为 AI 生成约束，输出可预览的页面草稿。项目重点是让 AI 支持用户学习和决策，而不只是自动产出页面。仓库附代码、运行说明和项目介绍视频。

**较短版（表格字数有限时）**：

> 一款面向非设计用户的 AI 页面生成前置指引工具。通过需求澄清、信息架构与视觉方案的可视化选择，帮助用户理解并确认设计决策，再据此生成页面草稿。仓库含代码、运行说明和演示视频。

**填报提示**：当前仓库提供源代码与项目演示，不应将 GitHub Pages 静态预览写成可完整使用的线上 AI 服务；AI 功能需要服务端代理与 API Key。
